# [추석 축하 영상 — 스타일리시 에디션]

손그림 캔버스 애니메이션 기반의 "한국 추석 명절 축하" 영상을 MP4로 제작.
진행 순서: 에셋 준비 → 스토리보드 → 초안 스틸 확인 → 최종 렌더링
스킬·MCP 도구 없이 코드로 직접 제작.

## 톤 & 무드
- 손그림 선 떨림·종이 질감은 유지하되, 전체 완성도는 K-팝 뮤직비디오급으로 세련되게
- 비트에 맞춘 컷 전환, 강약이 분명한 줌·화면 흔들림, 무대 조명 같은 림라이트
- 과한 장식보다 여백과 정돈된 구도로 고급스러움 유지

## 주인공과 비주얼
- 주인공: 오리지널 8비트 픽셀 너구리 '송구리'
  (눈가의 검은 마스크 무늬, 통통한 줄무늬 꼬리, 클레이 오렌지 한복 조끼,
  반짝이는 눈, 등장·성공 시 아이돌 포인트 포즈)
- 오프닝 엠블럼: 송편과 보름달을 결합한 오리지널 심볼 → 송구리로 변신,
  이후 불꽃놀이·HUD 아이콘으로 반복 활용
- "Claude" 텍스트: 로고 형태가 아닌 얇은 명조체의 크레딧 문구로 사용
  - 오프닝 타이틀 아래 부제 "presented by Claude"
  - 엔딩 문구에 포함
- 팔레트: 아이보리 · 클레이 오렌지 · 딥 네이비/차콜
- 서체: 타이틀·미션 문구·HUD·엔딩까지 모든 글자를 얇은 명조체로 통일
  (Noto Serif KR Light 계열, 없으면 가장 가는 굵기의 명조체로 대체)
  - 작은 글자는 반투명 아이보리 패널 위에 배치해 가독성 확보

## 게임 규칙 (한눈에 이해되도록)
- 전통놀이 한 판 클리어 = 송편 획득
- 송편: 흰색·초록·분홍 반달 떡
- 상단 HUD: 송편 개수 + 달 채우기 진행률 게이지, 획득 시 팝 애니메이션

## 스토리
1. 오프닝: 엠블럼 → 송구리 등장 → 타이틀 + "presented by Claude"
2. 반쪽만 찬 달 → 미션 "송편을 모아 달을 채워라!"
3. 전통놀이 릴레이(윷놀이, 제기차기, 투호, 팽이치기, 연날리기, 강강술래)
   — 규칙과 도구는 검색해 정확하게, 놀이마다 짧고 강한 하이라이트 컷
4. 피날레 널뛰기: 점점 높이 뛰다가 슬로모션으로 달까지 비상
5. 비어 있던 달을 송편으로 채워 보름달 완성, 불꽃놀이 클라이맥스
6. 엔딩: "해피 추석 by Claude Opus 5.5"
